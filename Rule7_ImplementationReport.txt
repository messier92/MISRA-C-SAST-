## Implementation Report: `Rule7` Static Analysis Rules

### 1. Rules Implemented

- **MISRA-7-1-1 — Variables Not Modified Shall Be `const` Qualified ([`Rule711`](file:///c:/Users/HanLo/Projects/misra/src/rules/Rule7/Rule711.cpp)):**
  - Matches `FunctionDecl` definitions (`isThisDeclarationADefinition()`, `hasBody()`, excluding implicit declarations, virtual member functions, overloaded operators, and template declarations/instantiations) and analyzes non-`const` function parameters (`ParmVarDecl`) and local variables (`VarDecl` with `isLocalVarDecl() && !isStaticLocal()`).
  - Uses `FunctionVarAnalyzer` and `getDirectModifiedVar` to track variable modifications and reads by canonical `VarDecl*` identity across the function body (`CompoundStmt`), covering:
    - Direct and compound assignments (`=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, `>>=`) and overloaded assignment calls (`CXXOperatorCallExpr::isAssignmentOp()`).
    - Prefix and postfix increment/decrement operations (`++`, `--`) and overloaded `operator++`/`operator--`.
    - Address-of expressions (`&var`), non-`const` member function calls on value objects, reference arguments passed to functions or constructors (`LValueReferenceType`, `RValueReferenceType`), and array-to-pointer decay arguments.
  - Distinguishes pointer modification (`p = ...`, `++p`, `&p`) from pointee modification (`*p = ...`, `p[i] = ...`, `p->field = ...`) and checks outer pointer constness (`qt.isConstQualified()`, i.e. `T* const`) separately from pointee constness (`const T*`), flagging `const char* str` in `getNthChar(const char* str, int N)` while treating `const char* const str` in `getNthChar_const_safe(const char* const str, int N)` as compliant.
  - Excludes function parameters of integer, floating-point, enum, boolean, and reference types (`isExcludedParamType`) as required by the rule specification.

- **MISRA-7-3-1 — Global Namespace Declarations ([`Rule731`](file:///c:/Users/HanLo/Projects/misra/src/rules/Rule7/Rule731.cpp)):**
  - Inspects `TranslationUnitDecl` using `GlobalNamespaceContextScanner` and `GlobalNamespaceVisitor` to verify that only `main`, `namespace` declarations (`NamespaceDecl` and `NamespaceAliasDecl`), and `extern "C"` declarations (`LinkageSpecDecl` with `LinkageSpecLanguageIDs::C`) reside in the global namespace.
  - Traverses top-level declarations and skips traversing inside `NamespaceDecl` (both named and anonymous namespaces) and `extern "C"` `LinkageSpecDecl` blocks, while descending into `extern "C++"` linkage blocks and scanning function bodies for block-scope `extern` declarations (`isLocalExternDecl()`) whose semantic `DeclContext` is the global `TranslationUnitDecl`.
  - Exempts the global `main` function via `isGlobalMainFunction` (supporting both standard hosted mode `fd->isMain()` and `-ffreestanding` mode where top-level `main` is checked by identifier and semantic global context) and reports noncompliant global functions (`void foo(int32_t);`, `extern void foo3();`), global variables (`int32_t var1;`), global classes/structs/enums, and global typedefs/type aliases.

### 5. Known Limitations

- **Freestanding Compilation Flag (`-ffreestanding`) and `FunctionDecl::isMain()`:** Because `main.cpp` injects `-ffreestanding` into Clang's compilation arguments, Clang's `FunctionDecl::isMain()` returns `false` on `int main()`. `Rule731` accounts for this by checking both `fd->isMain()` and whether the non-local-`extern` function identifier is `"main"` declared directly in the top-level `TranslationUnitDecl`.
