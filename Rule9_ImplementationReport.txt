## Implementation Report: `Rule9` Static Analysis Rules

### 1. Rules Implemented

- **MISRA-9-3-1 — `const` Member Functions Returning Non-`const` Pointers or References to Class Data ([`Rule931`](file:///c:/Users/HanLo/Projects/misra/src/rules/Rule9/Rule931.cpp)):**
  - Matches `CXXMethodDecl` definitions (`isDefinition()`, `hasBody()`, excluding implicit declarations and uninstantiated function templates) that are `const`-qualified (`method->isConst()`).
  - Inspects the canonical return type (`method->getReturnType().getCanonicalType()`) to determine whether the member function returns a pointer or reference to a non-`const` pointee (`(canonRet->isPointerType() || canonRet->isReferenceType()) && !canonRet->getPointeeType().isConstQualified()`).
  - Traverses the member function body via `ReturnStmtCollector` (stopping at nested `LambdaExpr` and `CXXRecordDecl` boundaries) and inspects each returned expression using `refersToNonStaticClassData` and `hasThisBase`.
  - Distinguishes non-static data members (`FieldDecl` and `IndirectFieldDecl` accessed on `CXXThisExpr`, including `&rInt`, `this->field`, array subscripting, and pointer arithmetic) from `static` data members (`VarDecl`), local variables, parameters, and external objects, reporting at most one violation per offending member function.

- **MISRA-9-3-3 — Member Functions That Can Be Made `static` or `const` ([`Rule933`](file:///c:/Users/HanLo/Projects/misra/src/rules/Rule9/Rule933.cpp)):**
  - Matches non-static `CXXMethodDecl` definitions (`!method->isStatic()`, `hasBody()`, excluding implicit/defaulted/deleted methods, constructors `CXXConstructorDecl`, destructors `CXXDestructorDecl`, conversion operators `CXXConversionDecl`, overloaded operators `isOverloadedOperator()`, virtual methods `isVirtual()`, and template patterns/specializations).
  - Evaluates each member function in strict two-step priority order using `MethodAccessVisitor`:
    1. **Check 1 (`static` candidate — highest precedence):** Determines whether the function accesses any non-static data member (`FieldDecl` / `IndirectFieldDecl`) or calls any non-static member function on `CXXThisExpr`. Accesses to `static` data members (`VarDecl`, such as `m_s` in `foo3()`) or calls to global functions (`Connector()`) do not count as non-static class data accesses. If no non-static data member of `this` is accessed, the function is reported as a `static` candidate (even if already declared `const`).
    2. **Check 2 (`const` candidate):** If the function accesses non-static data members of `this` and is not already `const`, checks whether any non-static data member of `this` is modified via built-in or overloaded assignments (`=`, `+=`, `-=`, etc.), increments/decrements (`++`, `--`), non-`const` member calls on value fields, or passing non-reference value fields by non-`const` reference/pointer. Distinguishes modifying a pointer or reference member itself from accessing or returning the referenced/pointed-to object (`int16_t& getref() { return m_i_ref; }`).

- **MISRA-9-5-1 — Unions Shall Not Be Used ([`Rule951`](file:///c:/Users/HanLo/Projects/misra/src/rules/Rule9/Rule951.cpp)):**
  - Matches `RecordDecl` AST nodes where `isUnion()` is `true` (`recordDecl(isUnion())`), covering both named and anonymous unions declared at global scope, namespace scope, class/struct scope, or local function scope.
  - Excludes compiler-synthesized injected-class-name declarations (`rd->isImplicit()`) and implicit template instantiations (`TSK_ImplicitInstantiation`).
  - Deduplicates forward declarations and definitions of the same union by reporting the definition (`rd->isThisDeclarationADefinition()`) when present in the translation unit, or the canonical first declaration (`rd == rd->getCanonicalDecl()`) when only forward-declared.
